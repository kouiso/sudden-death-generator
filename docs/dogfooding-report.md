# dogfooding レポート

## 全体印象

**一致度 0%: 根本的に別物。** 通常形の1文字ズレから短冊・縦書きの完全崩壊まで、
「突然の死」ジェネレーターとして期待される最低限の表示品質を満たしとらん。

検証環境: `claude/suddenlydeth-refactor-preact-sn1u0q`（React Router v7 テンプレ実装）、
`npm run dev`、Chromium (Playwright, 1280×900, `locale: ja-JP`)。

---

## Before（旧実装 = React Router v7 版）

### ケース01: 通常形・単一行「突然の死」

```
＿人人人人人＿
＞　突然の死＜
￣Y^Y^Y^Y^Y^￣
```

**BUG**: 右側の `＜` の前に全角スペースが無い（左は `＞　突然の死` と空いとるのに右は詰まっとる）。
本来の正解は `＞　突然の死　＜` で左右対称。`人` の数も 5 個で、正解の 6 個より少ない。

### ケース02: 通常形・複数行「一行目 / 二行目はちょっと長い」

```
＿人人人人人人人人人人人＿
＞　一行目　　　　　　　＜
＞　二行目はちょっと長い＜
￣Y^Y^Y^Y^Y^Y^Y^Y^Y^Y^Y^￣
```

行ごとのパディング自体は揃っとるが、ケース01と同じく右側の空白が無い非対称。

### ケース03: 半角混在「ぬるぽ!!」

```
＿人人人人人＿
＞　ぬるぽ!!＜
￣Y^Y^Y^Y^Y^￣
```

同じ非対称バグ。半角文字混在時の桁ズレは今回の入力では顕在化しなかったが、
コード読解の時点で `padLine` が全角スペース単位でしか埋められない欠陥は残っている。

### ケース04: 四角形「突然の死」

```
┌─────┐
│　突然の死│
└─────┘
```

**BUG**: 右側に閉じの全角スペースが無い。左右非対称が四角形にも伝播している。

### ケース05: 短冊「突然の死」（スクリーンショット確認）

```
┏━━━━-┷-━━━━┓
┃ 突　然　の　死 ┃
┗━━━━━━━━━━┛
```

テキストとしての出力はこの形だが、**実機のスクリーンショットでは `writing-mode: vertical-rl`
の CSS 回転により罫線・文字がバラバラの縦位置に飛び、上下の枠がどこにあるか判読不能な状態で
表示される**。テキスト値と見た目が一致しない、AA として完全に破綻している。

### ケース06: ストレス・複数行「残業 / 休日出勤 / 上司の圧」

```
残業
　　　　↘
休日出勤
　　　　↘
上司の圧
　　　　↘
　　　上司の圧
　　　　↙
＿人人人人人＿
＞　上司の圧＜
￣Y^Y^Y^Y^Y^￣
```

想定と異なり、入力行は順番にジグザグへ消費されている（コード読解時点の「最終行だけ使い回す」という
懸念は実測では再現しなかった）。最後の「突然の死」パートが最終行のみになる挙動は仕様として妥当。
ただしここも右側の空白欠落バグは伝播している。

### ケース07: 縦書き（通常形 + 縦書きチェック）「突然の死」

スクリーンショットで確認: **「死」の文字が別の文字と重なって描画され判読不能**。
`writing-mode: vertical-rl` で AA 全体を丸ごと回転させているだけで、文字単位の縦書き字形変換が
存在しないため、罫線文字・矢印はおろか漢字そのものの表示位置まで壊れる。UI として使用不可。

### ケース08: 空入力

`<pre>` 要素自体が生成されず、何も表示されない（クラッシュはしないが機能として素通り）。

### コンソールエラー

`ERR_CONNECTION_RESET` × 8 — Vite HMR の WebSocket 接続断によるノイズ。機能的なバグではない。

## 確定した不具合一覧（新実装で必ず解消する）

| # | 不具合 | 深刻度 |
|---|---|---|
| 1 | 通常形・四角形・ストレスの全パターンで右側の閉じ全角スペースが欠落し左右非対称 | 高 |
| 2 | `人` の繰り返し数が本来より少ない（境界計算のズレ） | 中 |
| 3 | 短冊が CSS 回転で完全に判読不能になる | 致命的 |
| 4 | 縦書きが文字重なりで完全に判読不能になる | 致命的 |
| 5 | 「余白」オプションが存在しない | 機能欠落 |
| 6 | 生成ボタン必須（リアルタイムプレビューがない） | UX |
| 7 | 空入力時に無反応（フィードバックなし） | UX |

## After（新実装）

### 全体印象

**一致度 100%: 一致（意図した仕様との一致）。** Before で確定した7件の不具合は全て解消した。
検証は本番ビルド (`npm run build` → `npm run preview`) を Playwright で操作して実施
（詳細は `docs/test-spec.md` の B1–B15、15/15 PASS）。加えて、実際のユーザーとして遊び心のある
入力・エッジケースで触った結果を以下に記す。

### 確認した不具合の解消

| # | Before の不具合 | After |
|---|---|---|
| 1 | 右側の全角スペース欠落・左右非対称 | `＞　突然の死　＜` — 左右対称。半角+全角混在（`Wi-Fiが繋がらない!!`）でもピクセル単位で揃う |
| 2 | `人` の数が本来より少ない | 本体幅から枠幅を逆算する構造にしたため、常に正しい数になる |
| 3 | 短冊が CSS 回転で判読不能 | 文字ごとに縦一列の枠（`┏━┓/┃突┃/┃然┃/┃の┃/┃死┃/┗━┛`）で完全に判読できる |
| 4 | 縦書きが文字重なりで判読不能 | 文字列側で縦書きを組む方式に変更し、1文字1行で重なりなく表示される |
| 5 | 余白オプションが無い | 実装済み。枠の内側上下に空行が1行ずつ増える |
| 6 | 生成ボタン必須 | 撤廃。入力・オプション変更が即プレビューに反映される |
| 7 | 空入力時に無反応 | 既定文言「突然の死」にフォールバックし、常に何かが表示される |

### 追加で触ってみた所感（実際のユーザーとして）

- **長い一行**（「今日も残業確定のお知らせ」）: 枠が本文幅に正しく追従し、崩れなし
- **半角/全角混在**（「Wi-Fiが繋がらない!!」）: 右端の `＜` が完全に揃う。旧実装の1桁ズレが根絶されたことを
  スクリーンショットで目視確認済み
- **複数行の通常形**（「月曜日 / 仕事に行きたくない / 突然の死」）: 各行末の `＜` が縦に完全に揃い、
  最長行に合わせて短い行が自動でパディングされる。フォームに凝った入力をしても壊れない安心感がある
- リアルタイムプレビューは触感として一番効いている差別化点。元サイト3つ（osstech / sacnoha / ichitaso）は
  いずれも生成ボタン等の送信操作が必須という前提で構成されており、この体験を持つ実装は無い
- **制約の告白**: このサンドボックス環境では外部サイト（osstech / sacnoha / ichitaso）への実ブラウザ
  接続がネットワークポリシーでブロックされており、3サイトとの画面を並べたピクセル単位の比較はできなかった。
  機能面の比較は Phase 0 の調査時点で WebFetch を通じて確認済みの記述に基づく

### 残存する既知の制約（バグではなく仕様上の割り切り）

- ストレス形状は縦書きオプションの影響を受けない（ジグザグ蓄積ラインと縦書き枠の整合が取れないため、
  意図的に対象外とした。`render.ts` にコメントで明記）
- X/LINE はプロポーショナルフォントで表示されるため、共有先で AA がズレる（先方サービスの仕様であり
  こちら側では回避不能。UI 上に注記を表示している）
