## 読み方

- `.dc.html` はデザインキャンバス用の形式で、そのままブラウザで開いても表示されない（`support.js` はアーティファクト側にある）。
- 見た目の値（色・大きさ・余白・角丸・書体）は、各ファイルの `<style>` と `style="…"` に書いてある値が正。
- 明るい表示と暗い表示の色は、`.r`（明）と `.r[data-theme=dark]`（暗）の2つの定義にある。
- AA の表示に使っている書体（BIZ UDGothic）はデザイン上の代わり。実装の書体（`src/style/font.css`）は変えない。
